  2. HotN3: heróis em addons/hotn3_entities/entities.json (minions ent_minion_* usados só no apêndice de inimigos).
  3. Matching: normalização (minúsculas, sem acento, sem pontuação) + primeiro token (≥4 chars) + aliases (Delevingne↔Techna, Evelyn/Sombria, Taylor/Nave-Mãe, Konrad/Sicário/Armagedom, Nero Granger↔Nero, Dominika↔Dominika Seur, Alyssa Wine).   4. Prioridade de cartas: Fichas 3 quando o bloco tem ≥3 manobras nomeadas; senão lista em FICHAS - Manobras. Efeitos não inventados — só o texto da planilha. Propostas de mapeamento HotN3 são rótulo proposta.
  5. Dados incompletos: personagem entra mesmo assim (Kalel, Methos, Hibiki esboço…) com caixa de aviso.
  6. Fora do foco principal: abas MMS (referência Marvel), TEMPLATE de Fichas 3, blocos Manobras sem rótulo de personagem (água/arcano genéricos) — citados se úteis, não viram seção.
  7. Padrão de adaptação: mesmo léxico do doc dos 7 (Impacto→ATTACK, Armadura→protecao, etc.). Deck alvo: 5 Iniciais + Evoluídas + Melhoradas + 1 Desvantagem.
