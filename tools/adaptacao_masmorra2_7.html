Método

  1. Fonte de verdade: blocos em Fichas 3 (Evelyn, Techna, Taylor, Konrad, Madelyn). Dominika e Nero: lista em FICHAS - Manobras (+ nomes em Lista). Completar com Fichas 2 / Manobras quando Fichas 3 estiver vazia.
  2. Ignorar nomes/efeitos atuais no Extract e em entities.json/cards.json destes sete — redesenho só a partir da planilha.
  3. Padrão Alyssa (referência): Aprimoramento com stacks (Escuridão → variável E), Manobras ATTACK / ESTADO + DESVANTAGEM, flags (reach, free, exhaust, instant, lethargic, penetrating, final), ops (hit, protecao, barreira, resistente, status, heal, push/pull, summon, actions, requires_*, when_stacks), alvos (ENEMY, ENEMY_ROW, ALL_*, SELF, CHAIN…).
  4. Desvantagem: carta classe DESVANTAGEM, tipicamente Instantânea na mão. Se a planilha colou lixo (ex.: Evelyn = “Munição” da Techna), inventar desvantagem temática e marcar.
  5. Já existe = regra/op/status/flag já no motor HotN3. Precisa sistema novo = Aprimoramento novo, marcador, invocação especial, condição de derrota, etc.
  6. Deck: exatamente 5 Iniciais (únicas) + Evoluídas no pool + Melhoradas (Nome+) + 1 Desvantagem. Combate: 15 Manobras (3×5) + 3 Desvantagens + Combos se grupo compartilhado.
Léxico rápido planilha → HotN3: Impacto→ATTACK / attack · Poder→ATTACK / power + reach · Armadura/Escudo manobra→protecao / barreira / resistente · Atordoado→stun · Ferido→wounded · Fraco→weak · Forte→strengthened · Lento→slow · Frágil→fragil · Invulnerável→invulnerable · Sangramento→bleed · Grátis→free · Exaustão→exhaust · Letárgico→lethargic · Penetrante→penetrating · Instantâneo→instant · Final→final · Empurrar/Repulsão→push · Deslocamento→push/pull · Contra-ataque→counter · Atento (Alyssa)→ignora desvantagem de tipo / fere Invulnerável.

Nomenclatura oficial HotN3

Ver também docs/NOMENCLATURA.md no repositório.

  • Manobras = cartas Impacto / Poder / Estado. Cada personagem: 5 Iniciais (kit), Evoluídas (progresso), Melhoradas (versões Nome+, chrome 3D, melhorada_de).
  • Deck inicial de combate = 15 Manobras (3×5) + 3 Desvantagens (+ até 4 Combos se os 3 compartilham um grupo). Sem editor de deck in-game.
  • Reshuffle descarte→baralho: equipe aliada recebe Lento 1 (fadiga).
  • Desvantagem = 1 carta negativa por personagem.
  • Aprimoramento = passiva sempre ativa (substitui recurso / passive / assinatura como termos de design). Campo aprimoramento; aliases passive/signature.
  • Grupos (≈3 por personagem) → se time inteiro compartilha um grupo: +4 Combo Manobras Efêmeras (pares + trio). Jogável só com membros vivos; ao jogar, Manobras deles custam 0 INI no round.
  • UI ficha: retrato, attrs, tipo, Biografia, cartas (clique amplia + glossário de efeitos).
  • Batalha: botão Inspecionar; após alvo, prévia de dano (HP vermelho) + efeitos.
  • Editor: seções Inicial | Evoluídas | Melhoradas | Desvantagem; toggle Melhorada.
Pós-missão: sorteia 3 Manobras entre as dos participantes (incl. Evoluídas); se já possuem, oferece Melhorada.
