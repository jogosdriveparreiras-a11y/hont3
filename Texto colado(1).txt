Você está assumindo o papel de **lead game designer, lead Godot developer, technical artist, UI/UX designer, gameplay programmer e responsável por integração de assets** do projeto **Heroes of the Nightmare 3 — HotN3**.

Você tem acesso ao meu GitHub e deve trabalhar diretamente sobre ele.

O projeto de origem é:

**Repository:** `jogosdriveparreiras-a11y/HotN2`

O projeto atual é um jogo Godot 4.x chamado internamente de:

**Heroes of the Nightmare — Godot Edition**

O objetivo não é copiar código, arquivos, textos, personagens, imagens, efeitos visuais, interface, nomes de habilidades ou outros materiais proprietários de Marvel's Midnight Suns.

Não copie diretamente layout de UI, ilustrações, efeitos, sons, textos ou qualquer arquivo do jogo original.

O objetivo é atingir **profundidade mecânica comparável**, não reproduzir propriedade intelectual visual ou narrativa.

# 1. ESCOPO DO HOTN3

HotN3 deve ser um:

**RPG tático de equipes + deckbuilding de personagens + combate por cartas.**

A unidade fundamental do combate não é uma criatura invocada pela carta.

Cada carta representa uma ação executada por um personagem.

Exemplos:

- ataque;
- magia;
- defesa;
- cura;
- controle;
- contra-ataque;
- manipulação de posição;
- ataque em área;
- debuff;
- buff;
- combinação;
- habilidade especial;
- habilidade de classe;
- habilidade definitiva.

O jogador controla uma equipe de heróis.

Cada herói possui:

- atributos próprios;
- tipo;
- papel tático;
- deck próprio;
- habilidades próprias;
- animações próprias;
- identidade visual;
- sinergias;
- pontos fortes;
- vulnerabilidades.

Ao entrar na batalha, os decks dos personagens escolhidos são combinados em um **deck de combate compartilhado**.

A mão do jogador representa as ações que estão momentaneamente disponíveis para a equipe.

# 3. DIFERENÇA FUNDAMENTAL EM RELAÇÃO A MIDNIGHT SUNS

HotN3 NÃO terá movimentação livre de personagens pelo cenário.

Não haverá:

- grid;
- hexágonos;
- navegação livre;
- seleção de ponto no chão;
- pathfinding tático;
- deslocamento 360º;
- necessidade de caminhar até inimigos;
- mecânica baseada em coordenadas espaciais complexas.

Em vez disso, use o sistema próprio do HotN:

## ROW SYSTEM

Cada lado da batalha possui:

**FRONT ROW**

e

**BACK ROW**

A disposição básica deve funcionar visualmente como:

BACK ROW ALIADA

FRONT ROW ALIADA

———— CENTRO DA ARENA ————

FRONT ROW INIMIGA

BACK ROW INIMIGA

Os personagens ocupam slots visuais dentro dessas linhas.

O sistema deve suportar pelo menos 3 personagens aliados simultaneamente e quantidade variável de inimigos.

Não limite a arquitetura a exatamente três inimigos.

Chefes podem ocupar mais espaço visual ou slots especiais.

Reforços podem entrar durante a batalha.

# 4. REGRAS DO SISTEMA DE LINHAS

Transforme posicionamento em uma decisão tática relevante.

Ataques devem possuir propriedades como:

`MELEE`

`RANGED`

`MAGIC`

`AREA`

`PIERCING`

`CHAIN`

`ROW`

`ALL`

Ataques melee normalmente devem atingir personagens acessíveis na linha da frente.

A linha de trás deve receber alguma proteção enquanto personagens aliados estiverem protegendo a linha da frente.

Ataques ranged devem poder contornar parte dessas restrições.

Magias podem possuir suas próprias regras.

Algumas cartas podem:

- mover o usuário para a frente;
- mover o usuário para trás;
- trocar posição com aliado;
- puxar inimigo da back row para front row;
- empurrar inimigo da front row para back row;
- quebrar formação;
- impedir mudança de row;
- proteger aliados da linha de trás;
- atacar toda uma row;
- perfurar front row e atingir back row;
- encadear ataque entre personagens;
- atacar os dois slots mais próximos;
- atravessar um alvo;
- atingir todos em uma linha.

Essa será a substituição estrutural das decisões espaciais de Midnight Suns.

Não tente simular movimentação livre escondida.

O sistema de rows deve ser tratado como mecânica própria.

# 7. MÃO DE CARTAS

Durante batalha:

- cartas são compradas do deck;
- entram na mão;
- podem ser jogadas;
- podem ser descartadas;
- podem ser redesenhadas;
- algumas podem permanecer na mão;
- algumas podem ser exauridas.

Mantenha mão máxima configurável.

Use valores próximos à experiência desejada, mas todos os números devem ficar centralizados em configurações de balanceamento.

Nada importante deve estar espalhado como magic numbers pelo código.

# 8. CARD PLAYS

O jogador deve possuir um número limitado de **Card Plays** por turno.

Comece com:

**3 ações principais por turno.**

Isso combina com o que aparentemente já existe no HotN2.

Cartas comuns normalmente consomem uma ação.

Algumas cartas podem:

- custar zero;
- devolver a ação caso cumpram condição;
- consumir duas ações;
- gerar ação;
- não consumir ação;
- modificar o máximo de ações.

Crie interface clara indicando:

**AÇÕES: 3/3**

O número deve atualizar imediatamente.

# RESULTADO ESPERADO

Ao concluir, **Heroes of the Nightmare 3** deve ser um RPG tático por cartas no qual três personagens entram em uma arena 3D de fantasia como sprites 2D flat, ocupando posições de front e back row.

O jogador utiliza uma mão compartilhada de cartas pertencentes aos integrantes do grupo.

As cartas possuem apresentação física 3D e utilizam uma identidade gráfica comum, incluindo o mesmo background base.

O jogador precisa administrar:

ações

mão

deck

redraws

Ímpeto

tipos

status

sinergias

front/back row

prioridade dos inimigos

missão.

As batalhas precisam combinar:

decisão tática

deckbuilding

gestão de recurso

composição de equipe

sinergias

controle

dano

defesa

combos

animações cinematográficas.

A apresentação deve misturar deliberadamente:

**ambiente 3D detalhado**

+

**personagens 2D flat**

+

**cartas 3D**

+

**UI 2D limpa**

criando uma identidade visual própria.

O sistema deve buscar a riqueza tática e a fluidez que tornam o combate de Marvel's Midnight Suns interessante, mas o produto final deve ser inequivocamente:

**Heroes of the Nightmare.**
